# DigitRoller

Интерактивная браузерная демонстрация, анимирующая переходы между числовыми значениями с помощью прокручиваемых барабанов цифр.

## Веб-адрес

[digit-roller.d9911.org](https://digit-roller.d9911.org/)

## Возможности

- Анимирует первую числовую последовательность в двух редактируемых значениях.
- Поддерживает целые и дробные цифры, включая разделители `.` и `,`.
- Циклически прокручивает цифры от 0 до 9, а нецифровой текст меняется сразу.
- Поддерживает светлую и тёмную темы, а также английский, испанский и русский интерфейс.

## Использование

1. Введите текущее и новое значения; вокруг числа можно добавить текст.
2. Нажмите **Анимировать**, чтобы переключаться между двумя значениями.
3. Измените текущее значение, чтобы обновить предпросмотр, пока оно отображается.

## Локальный запуск

Это статический сайт. В корне репозитория запустите любой статический HTTP-сервер, например:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).
